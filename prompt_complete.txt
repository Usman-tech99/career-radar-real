SECTION 1 ΓÇö PROJECT VISION: AI-Powered Career GPS
Career Radar is NOT just an opportunity platform. It is the Google Maps of careers for Pakistani students, Gen Z learners, and freelancers.
Analogy | Meaning
Google Maps | Does not build roads ΓÇö helps you navigate existing roads
Career Radar | Does not create opportunities ΓÇö helps users navigate their career path with AI
Core difference | Student ΓåÆ AI Analysis ΓåÆ Personal Roadmap ΓåÆ Skills ΓåÆ Opportunities ΓåÆ Employment
Three Core Pillars:
Pillar | What It Means
NAVIGATE | AI builds personalized Career Blueprint based on degree, skills, goals
SCORE | Career Radar Score (0ΓÇô100) tracks progress like a credit score for careers
CONNECT | Real jobs, internships, courses ΓÇö matched to user profile from live database

SECTION 4 ΓÇö USER SYSTEM & ROLES (4 Tiers)
Role | Permissions & Redirect
super_admin (Founder) | One account. Created manually in Supabase dashboard. Full access to everything. Only role that creates/deletes accounts. After login ΓåÆ /admin/dashboard
admin (Volunteers) | Created by Founder. Full CRUD on all content. Can edit anyone's posts. CANNOT create users or access manage-team. After login ΓåÆ /admin/dashboard
collaborator (Partners) | Created by Founder. Login = /admin/my-profile page ONLY. Can update own bio, photo, links. NO other access. After login ΓåÆ /admin/my-profile
user (Public Members) | Self-register on website. Gets /dashboard with Blueprint + Score. No admin access. After login ΓåÆ /dashboard
Login Redirect Logic (AuthContext.jsx):Check user_roles table after every login:  super_admin  ΓåÆ  /admin/dashboard  admin        ΓåÆ  /admin/dashboard  collaborator ΓåÆ  /admin/my-profile  no row found ΓåÆ  /dashboard  (public user)

AI-powered career GPS for Pakistani students and freelancers.  Be helpful, concise, encouraging. Never fabricate data.  If user writes Roman Urdu, respond in Roman Urdu.  Modes: CAREER COACH (advice), JOB MATCHER (match from LIVE JOBS below),  CONTENT GUIDE (recommend from LIVE CONTENT below).  LIVE JOBS: ${JSON.stringify(jobs)}  LIVE CONTENT: ${JSON.stringify(content)}`;  // Cap at last 20 messages  const trimmed = messages.slice(-20);  // Call Gemini 2.0 Flash  const res = await fetch(    `https://generativelanguage.googleapis.com/v1beta/models/gemini-2.0-flash:streamGenerateContent?key=${Deno.env.get("GEMINI_API_KEY")}`,    { method:"POST", headers:{"Content-Type":"application/json"},      body: JSON.stringify({        system_instruction:{parts:[{text:system}]},        contents: trimmed.map(m=>({role:m.role==="assistant"?"model":"user",parts:[{text:m.content}]})),        generationConfig:{maxOutputTokens:1024,temperature:0.7}      })    }  );  return new Response(res.body,{headers:{...cors,"Content-Type":"text/event-stream"}});});
